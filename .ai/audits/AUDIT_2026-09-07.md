## Audit Findings & Remediation

### [SEC-03]: Potential Project Rate Limiter Bypass on Literal `'anonymous'` String
- **Severity:** P3 — Minor
- **Category:** Security & Rate Limiting
- **Location:** `benchmarks/server.py#L48`
- **Description:** `is_project_rate_limited()` checked `if not project_hash or project_hash == "anonymous": return False`. While `validate_and_sanitize_payload` hashes project names by default, a client explicitly constructing a payload with `"project_hash": "anonymous"` could theoretically bypass the 10-submissions/day project quota (relying solely on IP rate limiting).
- **Remediation:** Remove the `"anonymous"` bypass exemption in `server.py` and `pxos-benchmark.py`. All project hashes, including default anonymous hashes, must be subject to the daily quota to ensure uniform rate governance.
- **Status:** Remediated & Verified

---

### [REL-08]: Deterministic Git Extractor Fallback on Single-Commit Repositories
- **Severity:** P3 — Minor
- **Category:** Reliability & Edge Cases
- **Location:** `scripts/pxos-benchmark.py#L110-L125`
- **Description:** When `base_ref` is unspecified, `extract_git_metrics()` defaults to `git diff --numstat HEAD~1`. In newly initialized repositories containing exactly 1 commit, `HEAD~1` is an invalid git revision, causing `git diff` to return a non-zero exit code and reporting 0 lines added.
- **Remediation:** Add fallback detection: if `git diff --numstat HEAD~1` fails, query git for root commit via `git hash-object -t tree /dev/null` (or empty tree hash `4b825dc642cb6eb9a060e54bf8d69288fbee4904`) to diff the initial commit cleanly against the empty tree.
- **Status:** Remediated & Verified
