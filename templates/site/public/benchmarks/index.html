Empirical Methodology & Data Governance

How PXOS ensures zero data poisoning and transparent research verifiability.

Tier A Qualification Standard

Submissions require adherence_score >= 80, passing unit tests, and verified git diff metrics. Exploratory runs (Tiers B & C) are strictly partitioned.

Zero PII Privacy Invariant (INV-001)

Zero proprietary code or unhashed project identifiers are stored or transmitted. All project names are permanently SHA-256 hashed on client dispatch.

Anti-Poisoning Deduplication

Cryptographic session_fingerprint with SQLite UPSERT prevents Sybil duplicate submissions. Hourly rate limiting and 24h project submission quotas protect dataset integrity.
